## Projects

The portfolio currently features projects covering different areas of engineering and technology.

### IoT Flood Alert System

An IoT-based flood monitoring and alert system designed to monitor environmental conditions and provide early warnings.

The system combines sensor data with weather forecast information retrieved through an ESP32. When critical conditions are detected, alerts can be sent to users to support timely evacuation and risk mitigation.

**Technologies:**

- Arduino IDE
- C++
- ESP32
- APIs
- IoT

### Solar Cell Characteristics

A MATLAB/Simulink project focused on analyzing the electrical characteristics of photovoltaic solar cells.

The project investigates:

- I-V characteristics
- P-V characteristics
- Effects of irradiance
- Effects of temperature
- Maximum Power Point (MPP)
- Solar-cell efficiency
- Fill factor

The simulations examine how photovoltaic performance changes under different irradiance and temperature conditions.

**Technologies:**

- MATLAB
- Simulink
- Photovoltaic Systems
- Solar Energy

### Coupled Tank Control System

A control engineering project involving the modeling, simulation, linearization, and control of a coupled two-tank liquid-level system.

The project includes nonlinear system modeling, MATLAB/Simulink simulation, equilibrium-point analysis, state-space representation, pole placement, and Linear Quadratic Regulator (LQR) control.

**Technologies:**

- MATLAB
- Simulink
- Control Engineering
- State-Space Modeling
- LQR
